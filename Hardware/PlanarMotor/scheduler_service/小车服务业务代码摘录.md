## 1. 边缘电机服务 MotorService

**源文件：** `internal/edge/motor_service.go`

**职责：** 在 Edge 端独立运行，监听 NATS 指令（`move` / `release`），模拟小车运输过程，完成后上报到达事件。

### 1.1 服务说明

```go
// motor_service.go — 平面电机独立服务
//
// MotorService 是独立于 ManagedDevice 的运输服务：
//   - 监听 NATS motor.control.move / motor.control.release
//   - 模拟小车运输过程
//   - move 完成后发布 motor.status.arrived
//
// 与 ManagedDevice 的关键区别：
//   - 不注册、不心跳、不参与设备生命周期
//   - 订阅 subject：bioflow.{tenant}.{env}.{lab}.device._.motor.control.>
//   - 不需要 busy/idle 状态管理（可以同时处理多台小车的指令）
```

**Python 适配：** `class MotorService:`，使用 `nats-py` 异步连接；不注册、不心跳、不参与设备生命周期，可同时处理多台小车指令。

### 1.2 从 subject 提取动作类型

```go
// getMotorAction 从 subject 中提取 action（"move" 或 "release"）。
// subject 格式: bioflow.*.*.*.device._.motor.control.{action}
// action 在第 9 段
//
// Python 适配：def _get_motor_action(subject: str) -> str:
//     parts = subject.split(".")
//     if len(parts) >= 9 and parts[8] in ("move", "release"):
//         return parts[8]
//     return "unknown"
func getMotorAction(subject string) string {
    parts := strings.Split(subject, ".")
    if len(parts) >= 9 {
        action := parts[8]
        if action == "move" || action == "release" {
            return action
        }
    }
    return "unknown"
}
```

### 1.3 服务结构体

```go
// MotorService 平面电机运输服务（独立于设备体系）。
//
// Python 适配：
//   class MotorService:
//       def __init__(self, nc, tenant, env, lab, motor_name, mock_mode=True):
//           self.nc = nc
//           self.tenant = tenant
//           self.env = env
//           self.lab = lab
//           self.motor_name = motor_name      # 如 "planar_motor-1"
//           self._stopped = asyncio.Event()  # 替代 chan struct{}
//           self.mock_mode = mock_mode
type MotorService struct {
    nc        *nats.Conn
    tenant    string
    env       string
    lab       string
    motorName string  // 电机标识名（如 "planar_motor-1"）
    stopped   chan struct{}
    wg        sync.WaitGroup
    mockMode  bool
}

// NewMotorService 创建电机服务实例。
// Python 适配：即 __init__ 构造器
func NewMotorService(nc *nats.Conn, tenant, env, lab, motorName string, mockMode bool) *MotorService {
    return &MotorService{
        nc:        nc,
        tenant:    tenant,
        env:       env,
        lab:       lab,
        motorName: motorName,
        stopped:   make(chan struct{}),
        mockMode:  mockMode,
    }
}
```

### 1.4 启动与停止

```go
// Start 订阅 motor.control.> 并开始监听小车命令。
//
// Python 适配：
//   async def start(self):
//       motor_subj = f"bioflow.{self.tenant}.{self.env}.{self.lab}.device._.motor.control.>"
//       async def _on_msg(msg):
//           cmd = json.loads(msg.data)
//           task_id = cmd.get("task_id", "")
//           action = self._get_motor_action(msg.subject)
//           if task_id:
//               asyncio.create_task(self._handle_motor_cmd(task_id, action))
//       self._sub = await self.nc.subscribe(motor_subj, cb=_on_msg)
func (m *MotorService) Start() {
    if m.nc == nil {
        log.Printf("[motor:%s] NATS not connected, skip start", m.motorName)
        return
    }

    // 只订阅 motor.control.> — 不订阅 cmd.>
    motorSubj := fmt.Sprintf("bioflow.%s.%s.%s.device._.motor.control.>", m.tenant, m.env, m.lab)
    m.nc.Subscribe(motorSubj, func(msg *nats.Msg) {
        var cmd map[string]interface{}
        if err := json.Unmarshal(msg.Data, &cmd); err != nil {
            return
        }
        taskID, _ := cmd["task_id"].(string)
        action := getMotorAction(msg.Subject) // "move" or "release"
        log.Printf("[motor:%s] motor.control.%s received: task=%s", m.motorName, action, taskID)
        if taskID != "" {
            m.wg.Add(1)
            go m.handleMotorCmd(taskID, action)
        }
    })

    log.Printf("[motor:%s] subscribed: %s", m.motorName, motorSubj)
}

// Stop 停止服务。
// 等待所有正在处理的任务 goroutine 结束。
// Python 适配：async def stop(self) — 取消订阅并等待所有任务完成
func (m *MotorService) Stop() {
    close(m.stopped)
    m.wg.Wait()
}
```

### 1.5 处理小车命令

```go
// handleMotorCmd 处理小车命令。
//
// 云台服务下发两个 action：
//   - move    → 模拟运输 3s → 回复 motor.status.arrived
//   - release → 静默执行    → 不回复（无进度日志）
//
// Python 适配：
//   async def _handle_motor_cmd(self, task_id: str, action: str):
//       if action == "release":
//           return                       # release 静默执行
//       if self.mock_mode:
//           await self._sim_exec(task_id, 3.0)   # 模拟 3 秒运输
//       else:
//           # 真实模式：后续对接真实小车驱动
//           # TODO: 实现真实小车控制
//       if action == "move":
//           await self._publish_motor_arrived(task_id)
func (m *MotorService) handleMotorCmd(taskID, action string) {
    defer m.wg.Done()

    // release 静默执行（无延迟）
    if action == "release" {
        log.Printf("[motor:%s] release done: task=%s", m.motorName, taskID)
        return
    }

    log.Printf("[motor:%s] MOTOR task=%s action=%s", m.motorName, taskID, action)

    if m.mockMode {
        m.simExec(taskID, 3.0)  // 模拟 3 秒运输
    } else {
        // 真实模式：后续对接真实小车驱动
        // TODO: 实现真实小车控制
        log.Printf("[motor:%s] [TODO] real motor control not yet implemented, task=%s", m.motorName, taskID)
    }

    // move 完成后上报已到达
    if action == "move" {
        m.publishMotorArrived(taskID)
    }
}
```

### 1.6 模拟执行（定时等待）

```go
// simExec 模拟执行（定时等待，输出进度条）。
// 模拟 3 秒运输过程，每 500ms tick 一次。
//
// Python 适配：
//   async def _sim_exec(self, task_id: str, dur: float):
//       if dur < 1:
//           dur = 3
//       tick_interval = 0.5  # 500ms
//       total_ticks = max(1, int(dur / tick_interval))
//       for i in range(1, total_ticks + 1):
//           if self._stopped.is_set():   # 中途停止
//               return
//           await asyncio.sleep(tick_interval)
//           # 进度日志可保留为 debug 日志
func (m *MotorService) simExec(taskID string, dur float64) {
    if dur < 1 {
        dur = 3
    }
    tickInterval := 500 * time.Millisecond
    totalTicks := int(dur * 1000 / float64(tickInterval.Milliseconds()))
    if totalTicks < 1 {
        totalTicks = 1
    }
    ticker := time.NewTicker(tickInterval)
    defer ticker.Stop()

    for i := 1; i <= totalTicks; i++ {
        select {
        case <-m.stopped:
            return
        case <-ticker.C:
        }
        elapsed := float64(i) * float64(tickInterval) / float64(time.Second)
        _ = elapsed
        pct := int(float64(i) / float64(totalTicks) * 100)
        if pct > 100 {
            pct = 100
        }
        // progress 日志已注释
        // if pct >= 100 || pct%20 == 0 {
        // 	log.Printf("[motor:%s] [%s] %3d%% %.1f/%.1fs task=%s",
        // 		m.motorName, progressBarMotor(pct, 30), pct, elapsed, dur, taskID)
        // }
        _ = pct
    }

    log.Printf("[motor:%s] DONE task=%s", m.motorName, taskID)
}
```

### 1.7 上报到达事件

```go
// publishMotorArrived 发布 motor.status.arrived 事件。
//
// Python 适配：
//   async def _publish_motor_arrived(self, task_id: str):
//       subject = f"bioflow.{self.tenant}.{self.env}.{self.lab}.device._.motor.status.arrived"
//       payload = {
//           "task_id": task_id,
//           "device_id": self.motor_name,
//           "timestamp": datetime.now(timezone.utc).isoformat(),
//       }
//       await self.nc.publish(subject, json.dumps(payload).encode())
func (m *MotorService) publishMotorArrived(taskID string) {
    subject := fmt.Sprintf("bioflow.%s.%s.%s.device._.motor.status.arrived", m.tenant, m.env, m.lab)
    payload := map[string]interface{}{
        "task_id":   taskID,
        "device_id": m.motorName,
        "timestamp": time.Now().Format(time.RFC3339),
    }
    body, _ := json.Marshal(payload)
    if err := m.nc.Publish(subject, body); err != nil {
        log.Printf("[motor:%s] publish arrived failed: %v", m.motorName, err)
    } else {
        log.Printf("[motor:%s] arrived published: %s", m.motorName, taskID)
    }
}
```

### 1.8 字符进度条（辅助函数）

```go
// progressBarMotor 绘制字符进度条（独立的版本，避免与 managed_device.go 耦合）。
//
// Python 适配：可迁移，但当前进度日志已注释，此函数在 Python 版本中可选。
func progressBarMotor(pct, width int) string {
    filled := pct * width / 100
    if filled > width {
        filled = width
    }
    return strings.Repeat("█", filled) + strings.Repeat("░", width-filled)
}
```

## 5. 整体交互流程（边缘端视角）

│        ▲                                        │             │
│        │ motor.status.arrived                   │ NATS        │
│        │ (推进运输任务)                          ▼             │
│  ┌──────────────────────────────────────────────────────┐     │
│  │                    NATS Broker                        │     │
│  └──────────────────────────────────────────────────────┘     │
│        ▲                                        │             │
│        │ 上报 arrived                            │ 下发指令     │
│        │                                        ▼             │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │              边缘端 MotorService                         │   │
│  │                                                         │   │
│  │  订阅 motor.control.>                                   │   │

## Python 迁移要点

| Go 特性 | Python 对应 |
|---------|-----------|
| `struct` / `type` | `@dataclass` 或 `TypedDict` |
| `chan struct{}` (stop signal) | `asyncio.Event()` |
| `sync.WaitGroup` | `asyncio.gather()` / `asyncio.create_task()` |
| `go func()` (goroutine) | `asyncio.create_task()` |
| `time.NewTicker` | `asyncio.sleep()` 循环 |
| `nats.Conn` / `Subscribe` | `nats-py` 的 `nc.subscribe` |
| `nc.Publish` | `await nc.publish(subject, payload_bytes)` |
| `json.Marshal/Unmarshal` | `json.dumps/loads` |
| `log.Printf` | `logging` 模块 |
| `time.RFC3339` 格式化 | `datetime.now(timezone.utc).isoformat()` |
| `fmt.Sprintf` | f-string |
| `strings.Split/Join` | `str.split/join` |
| `strings.Repeat` | `str * int` |
